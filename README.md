# 📈 Stock Analyzer (ストック・アナライザー)

豊富な分析エンジンとAIを活用した、個人投資家向けの本格的な米国株・日本株（SP500・日経225）ダッシュボードアプリです。

## 🚀 主な機能
- **Scoreboard / Dashboard**: 銘柄のスコアリング・チャート及びAI分析
- **Quick Analysis**: 過去数年分の財務諸表グラフ
- **News & Correlation**: 最新ニュースの取得と、銘柄間の相関関係（Correlation）分析
- **AI Service**: スコアリング及びニュースを元にしたAI分析及びHPへのリンク
- **履歴管理**: サイドバーでのトグルスイッチによるスマートな検索履歴の保存・削除機能（ブラウザ連動）

## 🛠️ 推奨環境・セットアップ

1. **必要ライブラリのインストール**
   ```bash
   pip install -r requirements.txt

## 🏃‍♂️ 起動方法

ターミナル（またはコマンドプロンプト）を開き、プロジェクトのルートディレクトリで以下のコマンドを実行してStreamlitアプリを起動します。
    ```bash
    streamlit run main_app.py

### 💡 マスターデータ（銘柄リスト）更新について
